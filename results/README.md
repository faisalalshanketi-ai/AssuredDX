# Released results

Outputs of the runs reported in the paper. Trained models, data splits and dataset rows are not included; they are regenerated by the scripts.

| Folder | Run |
|---|---|
| `ciciot2023_k5/` | CICIoT2023, artefact-free features, k = 5, stages 4-14 (main results) |
| `edgeiiot_k5/` | Edge-IIoTset, port-free model, k = 5, stratum mask, stages 4-14 (diagnosis attack on all 120 alerts per family) |
| `ciciot2023_k10/` | CICIoT2023, k = 10 sensitivity analysis (summaries only) |
| `detection_and_explanations/` | Stage 0-3 outputs: manifests, detector metrics, feature roles, global SHAP importance, diagnosers, decoy groups, and `detection_numbers.md` |

Inside each attack run:

| Path | Content |
|---|---|
| `attack_config.json` | All settings of the run |
| `stage4/alerts.csv` | Attacked alerts: test row, family, source capture, decoy family, subsets |
| `stage5/summary.json` | Validation scores of every diagnoser and the selected σ |
| `stage6/clean.jsonl` | Clean explanation, diagnosis and certificate of every defence, per alert |
| `stage7/attack_<defence>.jsonl` | Reference attack per alert and budget: eligibility, success, cost, score drift |
| `stage8/` | TMR, coverage, fidelity, sampling-budget and naive-smoothing tables |
| `stage9/diag_cert.jsonl`, `attack_vote.jsonl` | Diagnosis certificates and the attack on the smoothed diagnosis |
| `stage10/` | Diagnosis-certificate tables |
| `stage11/` | Decoder-aware attack on the unsmoothed decoder and on AssureDx |
| `stage12/` | Sharma et al. fingerprint and adapted Xue et al. masking-smoother results, clean audit |
| `stage14/attack_gate.jsonl` | AssureDx behind the fingerprint gate |
| `summary/` | Paired comparisons used in Tables 4-7 |
| `paper_numbers.md` | Summary numbers used in the text |
| `extended/` | Sample-flow accounting, per-stratum results, decoded-sample audit and accuracy equivalence (Tables S8-S11) |

Field `source_file` is the capture (CICIoT2023 file, or Edge-IIoTset capture block `#bN`) used for the capture-level bootstrap. Field `eps` may carry floating-point noise; round to four decimals.
